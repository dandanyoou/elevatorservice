    what am I looking at?

    Each column is a building with 3 elevators serving 10 floors. The same Poisson passenger arrivals (morning rush: lobby → upper floors) are fed to all three policies. The same seed = identical arrivals = fair comparison. Wait time accumulates; the policy with the lowest average wait wins.

    Glyphs: ↑/↓ = elevator direction, ●N = N passengers in car, ∎ = servicing (doors open), hollow triangles on the right of each floor = pending hall calls, the number beside them = passengers waiting on that floor.

    Built as a portfolio piece: PPO training is in progress and will drop in as a fourth lane when it can beat SCAN by 15% on average wait time. The whole dashboard is static — three pre-rendered JSON traces playing back from web/traces/. No backend, no WebSocket.
